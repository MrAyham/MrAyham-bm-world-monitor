# BM branding scope

Branding Market adaptation should affect the BM distribution surface, not erase upstream provenance.

## BM-owned surfaces

- Distribution title/description metadata
- BM AI OS navigation/return affordance
- Deployment-specific BM shell URL
- BM-specific defaults added deliberately after verification

## Upstream-owned surfaces to preserve

- License and copyright notices
- Upstream API/MCP naming where protocol compatibility depends on it
- Internal storage/session identifiers unless migration is designed
- Source attribution and provider labels
- Variant names used by upstream desktop/download/test contracts
